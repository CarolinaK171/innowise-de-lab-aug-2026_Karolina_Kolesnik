# Представленный набор данных состоит из 8 csv файлов (таблиц), каждая из которых содержит атрибуты отдельной сущности в рамках деятельности розничной сети Ecomarket:

## - sales.csv - фактовая таблица с данными о продажах продуктов розничной сети
## - customers.csv - справочная таблица с данными о покупателях
## - products.csv - справочная таблица с данными о продуктах
## - categories.csv - справочная таблица с данными о товарных категориях
## - employees.csv - справочная таблица с данными о сотрудниках
## - cities.csv - справочная таблица с данными о городах
## - countries.csv -справочная таблица с данными о странах
## - shops.csv - справочная таблица с данными о магазинах

# Связь между таблицами (сущностями) реализована за счет первичных и внешних ключей, уникальным образом идентифицирующих каждый элемент в рамках сущности.
