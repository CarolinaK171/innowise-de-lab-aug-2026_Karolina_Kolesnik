# *employees* - справочная таблица, уникальным образом идентифицирующая всех сотрудников сети Ecomarket по ключевому полю employee_id (первичный ключ). 

# По каждому сотруднику представлены следующие данные (атрибуты):
## * first_name - имя сотрудника
## * middle_initial - первая буква отчества
## * last_name - фамилия
## * birth_date - дата рождения
## * gender - пол
## * city_id - уникальный номер города (внешний ключ)
## * shop_id - уникальный номер магазина сети (внешний ключ)
## * hire_date - дата найма сотрудника


# *products* - справочная таблица, уникальным образом идентифицирующая все продукты, реализуемые в сети Ecomarket, по ключевому полю product_id (первичный ключ). 

# По каждому продукту представлены следующие данные (атрибуты):
## * product_name - название сотрудника
## * category_id - уникальный номер товарной категории продукта (внешний ключ)
## * class - класс продукта
## * modify_timestamp - дата изменения
## * resistant - идентификатор устойчивости продукта
## * is_allergic - идентификатор аллергенности продукта
## * vitality_days - срок годности продукта в днях

# Каждый атрибут представленной сущности является атомарным (т.е. не содержит повторяющихся групп, списков или нескольких значений в одной ячейке), что обеспечивает решение следующих задач:
## - Удобство поиска и фильтрации данных
## - Целостность данных
## - Отсутствие избыточности
## - Простой язык запросов
