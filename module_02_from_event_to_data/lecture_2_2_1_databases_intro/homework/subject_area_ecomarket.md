## Предметная область проекта EcoMarket

Предметной областью проекта **EcoMarket** является розничная торговля фермерскими и экологически чистыми товарами, реализуемыми в рамках одной сети магазинов.

## Структура данных

Структурно представленные в рамках проекта данные включают **8 файлов** в формате `CSV`, каждый из которых содержит характеристики (атрибуты) одной из сущностей, а именно данные о:

* продажах;
* покупателях;
* продуктах;
* товарных категориях;
* сотрудниках сети;
* городах;
* странах;
* магазинах сети.

## Фиксируемые операции

В рамках представленных данных фиксируются операции продажи отдельных продуктов сети. Каждая из операций характеризуется следующими параметрами:

* уникальным номером транзакции;
* номером продукта;
* номером клиента;
* номером сотрудника сети;
* количеством проданных единиц продукта;
* размером скидки;
* общей суммой продажи.
